# Texture Pack Switcher

A Fabric mod for Minecraft that makes managing resource packs faster and easier.  
Texture Pack Switcher allows you to create custom resource pack profiles and instantly switch between different texture pack combinations with a single key press.

## Features

- Create custom resource pack profiles
- Add multiple resource packs to each profile
- Switch between profiles instantly
- Automatically disables currently active resource packs
- Automatically enables the packs saved in the selected profile
- Simple in-game interface
- Customizable keybind support
- Lightweight Fabric implementation

## How It Works

Texture Pack Switcher replaces the need to manually open the Minecraft resource pack menu every time you want to change your setup.

Create a profile, select the resource packs you want to use, save it, and activate it whenever you need. The mod will handle the rest by removing your current packs and applying the selected profile automatically.

## Use Cases

Perfect for players who use different resource pack setups for:

- PvP
- Building
- Survival
- Screenshots
- Different Minecraft worlds
- Performance-focused setups

## Installation

1. Install [Fabric Loader](https://fabricmc.net/use/).
2. Install [Fabric API](https://modrinth.com/mod/fabric-api).
3. Download the latest Texture Pack Switcher `.jar` file.
4. Put the file into your Minecraft `mods` folder.
5. Launch Minecraft with the Fabric profile.

## Requirements

- Minecraft 1.21.11
- Fabric Loader
- Fabric API
- Java 21 or newer

The default keybind for opening the Texture Pack Switcher menu is: I
